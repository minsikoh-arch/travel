# 여행스킬

목적지에 맞춰 실용적인 2박 3일 여행 일정을 기본으로 만드는 Codex 스킬입니다. 관광지와 주변 식사를 동선에 맞춰 묶고, 비 오는 날 실내 대안과 관련 여행 블로그 링크를 제안합니다. 사용자가 다른 여행 기간을 지정하면 그 기간에 맞춥니다.

## 구성

- `SKILL.md`: 일정 조사와 작성 지침
- `agents/openai.yaml`: 스킬 표시 이름과 기본 요청 문구

## 사용

Codex에서 `여행스킬`을 사용해 여행지와 날짜를 알려주세요. 기본 일정은 2박 3일이며, 다른 기간이나 선호하는 여행 속도·관심사를 함께 적으면 그에 맞춰 조정합니다.
